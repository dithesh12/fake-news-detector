# Fake News Detection System

A machine learning project that classifies news articles as real or fake using NLP techniques.

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorization
- Joblib

## Features
- Text preprocessing using regex cleaning
- TF-IDF feature extraction
- Logistic Regression and Naive Bayes comparison
- Model accuracy evaluation
- CLI-based real-time prediction
- Model persistence

## Project Structure
- fake_news_detector.py – Main training and prediction script
- requirements.txt – Dependencies
- .gitignore – Ignored large and unnecessary files

## How to Run

1. Clone the repository:
   git clone https://github.com/dithesh12/fake-news-detector.git

2. Install dependencies:
   pip install -r requirements.txt

3. Download the Fake and True news CSV dataset and place them in the project folder.

4. Run:
   python fake_news_detector.py
